# 测试用例与执行说明

## 一、执行方式

```bash
# 全量执行（62 条）
python manage.py test accounts services orders appointments reports

# 单个学生功能包
python manage.py test accounts        # 学生 1（11 条）
python manage.py test services        # 学生 2（13 条）
python manage.py test orders          # 学生 3（12 条）
python manage.py test appointments    # 学生 4（13 条）
python manage.py test reports         # 学生 5（13 条）

# 页面与权限冒烟自检（40 个检查点，需先 seed_demo）
python manage.py selfcheck
```

每条用例都使用 Django `TestCase`（独立事务、自动回滚），测试数据由 `core/test_factory.py` 工厂构造，不依赖演示数据。
当前执行结果：**62/62 通过**。

## 八、已知边界与说明

- 附件上传用例使用独立 `media_test` 目录并在 tearDown 清理，不污染 `media/`。
- CSV 导出上限 5000 行、打印上限 300 行，避免教学环境大数据量导出阻塞。
- 统计区间倒置（开始 > 结束）时自动交换，不会报错。
- 订单/预约状态流转只允许 `STATUS_FLOW` 定义的路径，历史数据的状态由演示数据脚本初始化。
